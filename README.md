# Sarah Paine 學習空間

Sarah C. M. Paine 是美國海軍戰爭學院的榮譽退休教授，專長是俄羅斯與中國帝國史、海權戰略。她本人沒有自己的 YouTube 頻道，YouTube 上最主要的完整講座，幾乎都在 Dwarkesh Patel 的頻道，另外就是《Diary of a CEO》的長訪談。

本 repo 整理她在 YouTube 上主要的 11 支影片，按學習順序排列：框架 → 歷史案例 → 當代應用。

## 建議的學習順序

先看第 1 支建立框架，再看第 2–4 支的三部曲，接著是第 5–6 支東亞、第 7–8 支海權與冷戰，最後是第 9–11 支當代應用。

## 核心概念速記

- **大戰略**：整合外交、軍事、經濟、宣傳等所有國家力量工具，達成國家目標。
- **大陸強權 vs 海洋強權**：大陸強權靠領土擴張求安全，會燒掉財富；海洋強權靠貿易與規則秩序累積財富。
- **Death Ground（死地）**：把對手逼到絕境，對手別無選擇，只能拚死反抗。
- **勝利頂點**：在力量耗盡前停戰，保住已得的成果；超過頂點，勝利會變成災難。
- **有限目標 vs 無限目標**：目標有限的戰爭比較容易結束；追求政權更替等無限目標，往往引發叛亂與長期消耗。
